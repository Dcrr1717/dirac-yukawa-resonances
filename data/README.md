# Paper B — machine-readable data

Hartree atomic units (ħ = m = 1, c = 1/α = 137.035999084). Potential
`V(r) = -Z e^{-λr}/r`, reduced screening `s = λ/Z`. Energies are
binding-form (`E − c²`). Resonances follow the convention
`E = E_r − iΓ/2`: **`Gamma_half` columns are Γ/2 (half-widths),
`Gamma` columns are full widths.**

## Files

### `table_double_method.csv`
The double-method validation table of the manuscript (Table I,
`tab:double`): θ-stable complex-scaled spectral values vs. independent
Gamow shooting for the 2p doublet at s = 0.24. Transcribed exactly from
the LaTeX source.

### `table_production_2p.csv`
The production table (Table II, `tab:prod`): 2p doublet
(κ = +1: 2p₁/₂, κ = −2: 2p₃/₂), Z = 1–130, s ∈ {0.24, 0.30}.
`status` ∈ {resonance, bound, dissolved}; for `bound` rows the Hermitian
binding energy is in `Eb_*`; `dissolved` = too broad for the θ ≤ 0.8
window. Transcribed exactly from the LaTeX source (grid-spread precision
≤ 1e-10 unless noted in the manuscript; the Z=80, s=0.24, κ=+1 state is
basis-limited at 5e-9).

### `solver_grid_2p.csv`
Verbatim export of the solver's production output
(`feast-spectral` repo, `exploration/dirac_cs/f3_table.csv`, generated
by `f3_production.py`), with per-state grid spreads (`spread`) and the
relative spectral-vs-shooting deviation where the shooting anchor exists
(`shoot`; empty/nan where Γ ≳ 4 makes shooting unusable). `nan` rows
correspond to the `bound`/`dissolved` entries of the production table
(the E_b values live in the manuscript table, not in this file). `Gamma`
here is the full width.

### `shi_adjudication.csv`
State-by-state adjudication of the twelve resonances of Shi et al.,
Few-Body Syst. 55, 135 (2014). All 12 rows regenerated on 2026-07-29 by
running `exploration/dirac_cs/eb2c_shi_reproduction.py` (feast-spectral
repo; raw stdout archived as
`../reproducibility/eb2c_shi_reproduction_output.txt`). The run
reproduces the manuscript's claims exactly: 8 of 12 states at printed
rounding (`reproduced_upgraded` + the two `width_resolved` positions),
the two narrow A=170 states corrected (positions shifted ~1.5e-2,
widths overestimated ~100×), and the two "zero" widths resolved to
Γ = 3.04e-7 and 5.04e-7. Shi's setup: V = −A e^{−αr}/r, θ = 1.0,
HO basis; `alpha` column is their screening parameter. `published_*`
values are their 4-digit entries (E_r − iΓ/2 convention, same units).
Empty `shoot_agreement` = broad state beyond the Γ ≲ 4 shooting limit
(θ-stability only). The two broad A=170 states deviate in the 3rd digit
(`deviates_beyond_rounding`) but are not firmly adjudicated in the
manuscript because the independent shooting check is unavailable there.

### `f3_traj_Z80.csv`
The complex-plane trajectories of Fig.~1 (right panel): the $2p$ doublet
at Z = 80 as the reduced screening sweeps s = 0.245 → 0.30. Columns
`kappa`, `s`, `Er`, `Gamma` (full width). The κ = −2 partner has fewer
rows than κ = +1 because it dissolves out of the θ ≤ 0.8 window earlier.
Verbatim export of `exploration/dirac_cs/f3_traj.csv`.

### `grid_theta_N_beta.csv`
**The θ × N × β stability grid** — the machine-readable evidence behind
the honest-digits protocol described in the Methods section and behind
the abstract's "stable under rotation angle, basis size and scale to one
part in 10^10". Every tabulated state is measured on a 2 × 2 × 2 grid
(two rotation angles θ, two basis sizes N ≡ `nb`, two basis scales β),
and the quoted uncertainty is the maximum spread over that grid. This
file exposes the individual grid points for two representative states —
one moderate (Z = 40, κ = −2) and one near-threshold, basis-limited
(Z = 80, κ = +1) — so that the `spread` column of `solver_grid_2p.csv`
can be recomputed from raw numbers rather than taken on trust.
Generated by
`python f3_production.py --grid-dump 40,0.24,-2 --grid-dump 80,0.24,1 --grid-dump-out f3_grid_dump.csv`
(opt-in export mode; it never rewrites the production tables). 16 rows =
2 states × 2 `nb` × 2 `beta_factor` × 2 `theta`.

| column | meaning |
|---|---|
| `state` | state tag, `Z{Z}_s{s}_kappa{±κ}` |
| `Z` | nuclear charge |
| `s` | reduced screening λ/Z |
| `kappa` | Dirac quantum number κ (+1 = 2p₁/₂, −2 = 2p₃/₂) |
| `lam` | screening λ = sZ |
| `nb` | basis size N (200 or 240) |
| `beta_factor` | scale factor (0.25 or 0.40) |
| `beta` | basis scale β = `beta_factor` × max(Z, 1) |
| `theta` | complex-rotation angle θ in radians (0.45 or 0.60) |
| `Er` | resonance position Re E at this grid point |
| `Gamma` | **full** width −2 Im E at this grid point |
| `theta_pair_dev` | \|E(θ=0.60) − E(θ=0.45)\| for this (`nb`, `beta`) cell — the θ-stability quality of the pairing |
| `theta_matched` | 1 if the two angles matched an eigenvalue within the 1 % selector tolerance, so the cell contributes a value |
| `enters_spread` | 1 if this point's value survived the 5 % outlier filter and therefore enters the spread |
| `is_reference` | 1 on the single reference point (largest basis, largest scale: `nb`=240, `beta_factor`=0.40, θ=0.60), whose value is the quoted result |
| `dev_from_ref` | \|value − reference\| for this point; empty/`nan` where the point does not carry a collapsed value |

The collapsed value of a (`nb`, `beta`) cell is taken at the larger
angle, so `enters_spread` / `dev_from_ref` are populated only on the
θ = 0.60 rows. **The quoted spread is `max(dev_from_ref)` over the rows
with `enters_spread` = 1.** This reproduces the published values
exactly: 5.556e-11 for Z = 40, κ = −2 and 5.570e-09 for the
basis-limited Z = 80, κ = +1 state — the two `spread` entries of
`solver_grid_2p.csv` at s = 0.24.

### `d_doublet_thresholds.csv`
Critical screenings of the **3d fine-structure doublet** (κ = +2 = 3d₃/₂,
κ = −3 = 3d₅/₂), the doublet the manuscript names as the natural
continuation of the 2p study. Generated by

```
python ea3_critical_screening.py --kappas 2,-3 --zs 1,40,70,90,110,120,130 \
       --s-scan 0.070,0.099,0.001 --out d_doublet_thresholds_fine.csv
```

(`exploration/dirac/`, the bound-state engine of the companion paper).
Columns: `Z`; `kappa`; `Zalpha` = Zα; `lam_c` = critical screening λ_c at
which the level reaches threshold; `s_c` = λ_c/Z, the reduced critical
screening; `p_threshold` (threshold-law exponent used in the
extrapolation, 1.0 for ℓ ≥ 1); `spread` = spread of λ_c over the four
(basis size, basis scale) combinations, i.e. the *reproducibility* of the
extrapolation (1e-12 … 3e-8), **not** its systematic error; `ratio`
(`nan`: no tabulated nonrelativistic constant exists for this channel,
so the Z = 1 row *is* the computed nonrelativistic limit).

**The screening scan must be fine.** The engine's default scan (step
0.01 in s) is calibrated for the 2p channel at s_c ≈ 0.22; at the d
channel's s_c ≈ 0.09 that same step leaves too few bound points below
threshold and biases the extrapolation low by 2.5–4 %. The shipped file
uses step 0.001. Residual bias, measured against the direct brackets
below, is about −0.2 %.

The two channels are degenerate at Z = 1 (s_c = 0.091146 in both) and
split with Z, reaching 0.09589 (κ = +2) vs 0.09241 (κ = −3) at Z = 130 —
a 3.8 % relative splitting, against 39.5 % for the 2p doublet at the
same Z (see `ea3_critical_screening.csv` in the same repo directory).
Note s_c(d) ≈ 0.091–0.096 lies far *below* the 2p working screening
s = 0.24, which is why the d states are sampled near s ≈ 0.10 and not
near 0.24.

Independent verification at Z = 130 by direct bracketing with the
Hermitian solver (`eb_d_bound_check.py`, last bound s vs first unbound
s): s_c(κ = +2) ∈ (0.0960, 0.0965) and s_c(κ = −3) ∈ (0.0925, 0.0930).

### `d_doublet.csv`
Resonance parameters, bound-partner energies and shooting cross-check
for the 3d doublet near its own threshold, computed with the identical
θ × N × β protocol used for the 2p doublet (see
`grid_theta_N_beta.csv`).

| column | meaning |
|---|---|
| `Z`, `s`, `kappa` | state identification; s = λ/Z |
| `status` | `resonance` or `bound` (see criterion below) |
| `Er` | resonance position (empty for bound rows) |
| `Gamma` | **full** width −2 Im E (empty for bound rows) |
| `spread` | θ × N × β grid spread, the quoted uncertainty |
| `Eb` | Hermitian binding energy (bound rows only) |
| `s_over_sc` | s / s_c using the extrapolated s_c of `d_doublet_thresholds.csv` |
| `shoot_rel_dev` | **relative** deviation \|E_spec − E_shoot\| / \|E_shoot\| from the independent Gamow shooting |
| `shoot_R` | matching radius R used by the shooting |
| `shoot_R_drift` | max drift of the shooting value over R ∈ {0.8, 1.0, 1.25, 1.5} × R |

Empty `shoot_*` = the state lies outside the Γ ≲ 4 a.u. shooting domain.
`status` is decided by the manuscript's operational criterion — the
Hermitian (real-axis) solver of the same certified discretization
returning a negative binding energy — and **not** by `s_over_sc`; where
the two disagree marginally (the Z = 130, κ = −3, s = 0.0925 row has
`s_over_sc` = 1.0009 yet is bound) it is the −0.2 % extrapolation bias
in s_c described above, and the direct solver verdict governs.

Note the two accuracy regimes in `shoot_rel_dev`: the Z = 130, s = 0.095
state agrees to 5.8e-12 with R-drift 3.7e-9, whereas the Z = 40 and
Z = 90 states at s = 0.10 agree to ≈3e-8 with R-drift ≈3e-6 — there the
deviation is well inside the matching-radius sensitivity, so the
limitation is on the shooting side (the R = 18/λ heuristic is tuned for
the 2p case), not in the spectral values, whose grid spreads are 3e-11.

Generated by `f5_grid_noshoot.py` (spectral),
`f4_d_shooting_check.py` (shooting) and `eb_d_bound_check.py` (bound
partners); assembled into this file for the manuscript.

### `d_doublet_grid.csv`
Per-(θ, N, β) grid points for every state of `d_doublet.csv` (96 rows),
same column layout and same spread convention as
`grid_theta_N_beta.csv`. Rows whose `Er`/`Gamma` are `nan` are the
grid cells of the bound partners, where no eigenvalue exists in the
resonance search window — retained so the negative detections are
auditable too.
